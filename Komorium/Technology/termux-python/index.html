🐍 Termux: Python и первый скрипт

Часть 2. Пишем и запускаем код прямо на телефоне

📦 Установка Python

В Termux Python устанавливается одной командой. Откройте Termux и введите:

pkg install python

Дождитесь окончания установки. После этого Python станет доступен. Проверьте версию:

python --version

Вы увидите что-то вроде Python 3.12.x.

💡 Совет: Для установки дополнительных библиотек (например, requests) используйте pip install имя_библиотеки. Pip устанавливается автоматически вместе с Python.

👋 Первая программа

Создадим простой скрипт. В Termux можно использовать встроенный текстовый редактор nano. Если его нет, установите:

pkg install nano

Теперь создайте файл hello.py:

nano hello.py

В открывшемся редакторе напишите:

print("Привет, Komorok!")
name = input("Как тебя зовут? ")
print(f"Рад познакомиться, {name}!")

Сохраните файл: нажмите Ctrl+O, затем Enter, затем Ctrl+X для выхода.

📅 Полезный пример: сколько дней прошло с основания Komorok?

Этот скрипт похож на тот, который автоматически обновляет счётчик на главной странице сайта. Создайте файл days.py:

nano days.py

Вставьте следующий код:

import datetime

birthday = datetime.date(2026, 1, 1)
today = datetime.date.today()
days = (today - birthday).days

print(f"С момента основания Komorok прошло {days} дней.")

Сохраните и выйдите.

▶️ Запуск скриптов

Для запуска любого Python-файла используется команда python имя_файла.py. Попробуйте:

python hello.py
python days.py

Результат отобразится прямо в терминале. Если скрипт содержит ошибки, Python покажет сообщение с указанием строки.

💡 Кстати: именно так работают скрипты обновления счётчиков на Komorok. Они запускаются не вручную, а автоматически через GitHub Actions каждый день.
