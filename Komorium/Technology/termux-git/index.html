🔀 Termux: Git и работа с репозиторием

Часть 3. Клонируем Komorok и пушим правки прямо с телефона

📦 Установка Git

Git в Termux устанавливается одной командой:

pkg install git

После установки проверьте версию:

git --version

⚙️ Базовая настройка

Перед работой с репозиторием представьтесь Git’у — укажите имя и email. Они будут подписывать каждый ваш коммит.

git config --global user.name "Ваше Имя"
git config --global user.email "ваша@почта.com"

Можно проверить настройки:

git config --list

📥 Клонирование репозитория Komorok

Чтобы получить полную копию вашего сайта с историей изменений, выполните:

git clone https://github.com/Golova280809/Komorok.git

Эта команда создаст папку Komorok и загрузит в неё все файлы и коммиты. Если хотите клонировать сразу на SD‑карту, перейдите в нужную папку перед клонированием, например:

cd /storage/8396-0F0D
git clone https://github.com/Golova280809/Komorok.git

🔄 Работа с изменениями: pull, add, commit, push

Основные команды, которые понадобятся каждый день:

  • Обновить локальную копию с GitHub: 
    git pull
  • Добавить изменённые файлы в «список на коммит»: 
    git add .
  • Создать коммит с описанием: 
    git commit -m "Описание изменений"
  • Отправить коммиты на GitHub: 
    git push origin main

⚡ Полезные алиасы (короткие команды)

Чтобы не набирать длинные команды каждый раз, можно создать алиасы. Например, для обновления сайта:

echo "alias komorok='git -C /storage/8396-0F0D/Komorok pull'" >> ~/.bashrc
source ~/.bashrc

Теперь достаточно ввести komorok, и ваша локальная копия на флешке обновится до последней версии.

💡 Кстати: команда komorok1 (проверка ссылок) тоже использует Git и sitemap. Всё это живёт в Termux.
